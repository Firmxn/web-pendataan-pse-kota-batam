──────────────────────────────────────────────────────────────────
  TENTANG SISTEM
──────────────────────────────────────────────────────────────────

  Sistem ini merupakan aplikasi web untuk pendataan 
  Penyelenggaraan Sistem Elektronik (PSE) di lingkungan 
  Pemerintah Kota Batam.
  Aplikasi mengelola siklus hidup pendaftaran PSE, pengajuan
  subdomain, dan pengajuan hosting melalui alur verifikasi
  berjenjang dua level.


══════════════════════════════════════════════════════════════════
  ARSITEKTUR & ROLE-BASED ACCESS CONTROL (RBAC)
══════════════════════════════════════════════════════════════════

  Sistem menggunakan 5 role utama dengan pemisahan akses ketat:

  ┌──────────────────┬───────────────────────────────────────────┐
  │ ROLE             │ HAK AKSES                                 │
  ├──────────────────┼───────────────────────────────────────────┤
  │ Petugas (ID 1)   │ CRUD PSE, Subdomain, Hosting.             │
  │                  │ Submit pengajuan ke verifikasi.           │
  │                  │ Melihat status & riwayat milik sendiri.   │
  ├──────────────────┼───────────────────────────────────────────┤
  │ Verifikator 1    │ Verifikasi level 1 (kelengkapan admin).   │
  │ (ID 2)           │ Approve → teruskan ke Verifikator 2.      │
  │                  │ Reject → kembalikan ke petugas.           │
  ├──────────────────┼───────────────────────────────────────────┤
  │ Verifikator 2    │ Verifikasi final (persetujuan akhir).     │
  │ (ID 3)           │ Penerbitan dokumen & cetak PDF resmi.     │
  │                  │ Edit nomor registrasi PSE.                │
  ├──────────────────┼───────────────────────────────────────────┤
  │ Eksekutif (ID 4) │ Monitoring global (PSE, Subdomain, Host). │
  │                  │ Melihat laporan & rekapitulasi data.      │
  │                  │ Hak akses: Read-only.                     │
  ├──────────────────┼───────────────────────────────────────────┤
  │ Admin (ID 5)     │ Manajemen User (CRUD, restore, toggle).   │
  │                  │ Manajemen Master Data OPD.                │
  │                  │ Pemeliharaan & konfigurasi sistem.        │
  └──────────────────┴───────────────────────────────────────────┘

  FITUR UNGGULAN & PENYEMPURNAAN ROADMAP (TELAH SELESAI)
══════════════════════════════════════════════════════════════════

  Berikut adalah penyempurnaan strategis yang telah 
  diimplementasikan untuk menjamin kualitas sistem rilis pertama 
  (v1.0.0):

   1. Restriksi profil petugas (view-only, dikelola Admin).
   2. Modul manajemen pendaftaran & pengelolaan akun petugas.
   3. Akses profil terbatas (keamanan data petugas).
   4. Standarisasi sektor PSE (select/dropdown, bukan teks bebas).
   5. Konsolidasi alur bisnis terpadu (Integrated Single Flow).
   6. Penyatuan alur pendaftaran PSE, Subdomain, dan Hosting.
   7. Form pendaftaran adaptif & integrasi domain 1-N.
   8. Implementasi role baru: Admin & Eksekutif (monitoring).
   9. Dashboard khusus dengan filter data cerdas (real-time).
  10. Akses laporan rekapitulasi data lintas peran (PDF).
  11. Refactoring & Standardisasi database (OPD, User, PSE).
  12. Sinkronisasi Dokumentasi Arsitektur Sistem (Full Sync).
